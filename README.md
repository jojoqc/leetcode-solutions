# LeetCode Solutions

Repositorio personal con mis soluciones a ejercicios de [LeetCode](https://leetcode.com/), sincronizadas automáticamente en tiempo real mediante GitHub Actions.

## 🛠️ Automatización

Este repositorio utiliza [leetcode-sync](https://github.com/joshcai/leetcode-sync) para extraer mis soluciones con estado **Accepted** desde LeetCode, incluyendo el enunciado completo y las métricas de rendimiento.

## 📁 Estructura del Repositorio

Cada directorio representa un problema resuelto y contiene la descripción oficial junto con el código fuente de la solución:
